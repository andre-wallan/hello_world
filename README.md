# Hello World

## Overview

This project is a small first step in building my software engineering skills: a Python program with a reusable `greeting()` function that returns `Hello World!`, which the program prints to the screen. It gives me a simple, working project to practice writing, running, and documenting code.

I created it to get familiar with the basic development workflow and establish a starting point for future software projects.
